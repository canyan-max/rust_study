## 学习方法

- 每次一个小知识点：解释、短示例、学习者手写变式、根据报错复盘。
- 熟悉的条件判断等基础逻辑快速带过，重点练 Rust 特有规则。
- 尽量按 Rust 的思路理解，C 对比作为辅助；链式调用先拆开解释。
- 每阶段完成一次综合练习，将有价值的错误和理解补入 `Rust复盘笔记.md`。
- 按理解程度推进，不规定每天读多少页。
- 问语法或运行方式时先解释，不据此擅自修改代码、构建或启动程序。
