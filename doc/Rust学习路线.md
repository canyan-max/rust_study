## 教材与目标

- 主教材：《Rust 程序设计语言》简体中文版，共 549 页。
- 本地资料：`D:/program_CC/00_my_information/05_rust/doc/rust_learing.pdf`。
- 下文页码均对应这份 PDF；换版本后以章节名称为准。
- 已有 C 和 AT32 MCU 开发基础，现有 MCU 工程继续使用 C。
- 近期目标：在 Windows 上掌握 Rust，能够独立理解、修改串口协议解析和简单图形上位机；基础稳固后再规划嵌入式 Rust。

## 学习方法

- 每次一个小知识点：解释、短示例、学习者手写变式、根据报错复盘。
- 熟悉的条件判断等基础逻辑快速带过，重点练 Rust 特有规则。
- 尽量按 Rust 的思路理解，C 对比作为辅助；链式调用先拆开解释。
- 每阶段完成一次综合练习，将有价值的错误和理解补入 `Rust复盘笔记.md`。
- 按理解程度推进，不规定每天读多少页。
- 问语法或运行方式时先解释，不据此擅自修改代码、构建或启动程序。

- 第 17 章异步、第 18–20 章深入内容、第 21 章 Web 项目放在后续；先学明白线程版串口工具。
