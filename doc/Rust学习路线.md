## 每一节怎么复习

1. 用户先读网页，手敲或修改例子。
2. 只解释当前不理解的语句；有 C 基础的普通逻辑快速通过。
3. 给一个小变式验证理解，先提供所需方法、参数和返回类型，不默认直接给完整答案。
4. 用户反馈或代码检查后记录完成；没做的例子不记为已掌握。
5. 稳定知识收进 Rust复盘笔记，当前接续点只记在学习进度，避免新建重复文档。

库函数用到再查，不背方法列表。重点看接收类型、返回类型，以及借用、修改或移动原数据。
