## 常用函数速查

| 操作 | 作用与返回结果 |
| --- | --- |
| `std::env::args()` | 取得启动参数的迭代器 |
| `.collect()` | 收集为目标集合；本练习显式指定 `Vec<String>` |
| `std::fs::read_to_string(path)` | 读取 UTF-8 文本，返回 `Result<String, std::io::Error>` |
| `contents.lines()` | 逐行遍历，每行是 `&str`，不包含行尾换行符 |
| `line.contains(query)` | 判断是否包含关键词，返回 `bool`，区分大小写 |
| `text.as_str()` | 将 `String` 作为 `&str` 借用 |
| `line.to_string()` | 在本练习中，把 `&str` 复制成独立的 `String` |
| `Vec::new()` | 创建空容器；可显式写 `let mut result: Vec<String>` |
| `result.push(value)` | 在容器末尾加入元素 |
| `result.is_empty()` | 容器为空时返回 `true` |
| `text.to_lowercase()` | 返回转换为小写的新 `String`，原文本不变 |
| `assert_eq!(actual, expected)` | 检查实际结果与预期一致 |
| `assert!(condition)` | 条件为真时通过 |

`Vec<String>` 用 `{:?}` 可以整体调试打印；正常显示搜索结果时，用 `for line in &ret` 逐行打印。`{}` 不能直接打印整个 `Vec<String>`。

## 本轮所有权复盘

`search` 接收两个 `&str`，只借用关键词和文件内容。匹配后用 `line.to_string()` 创建每一行的独立字符串，再放进结果容器。

执行 `return result;` 时，容器所有权交给调用者的 `ret`。函数内变量 `result` 的作用域结束，但返回的数据由 `ret` 继续拥有。之后 `ret` 离开作用域且未再被转移时，容器和其中的字符串才释放。

现阶段继续使用 `Vec<String>`。教材中返回借用的行会用到生命周期标注，等当前逻辑稳固后再单独讲，避免同时增加陌生语法。

## 下一练习：忽略大小写搜索

只提供签名与方法，由学习者完成函数体：

```rust
fn search_case_insensitive(query: &str, contents: &str) -> Vec<String>
```

实现提示：

1. 循环前将关键词转为小写，避免每一行重复转换关键词。
2. 遍历正文，每行转小写后进行包含判断。
3. 判断时可用小写关键词的 `.as_str()`。
4. 加入结果的是原始行，不是转换后的小写行。
5. 没有匹配时返回空容器。

验收数据：正文仍用下面三行，关键词使用 `at32`。

```text
AT32 is running.
UART is ready.
AT32 sends data.
```

预期返回两行，仍保持 `AT32` 大写。另测不存在的关键词；原来的 `search` 对小写 `at32` 应不匹配这些大写行。
