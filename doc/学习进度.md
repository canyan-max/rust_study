## 当前成果

- A8 协议：校验、组包、借用式解包、半帧保留、连续多帧处理和错误后重新寻找帧头。
- Measurement：电压 u16、电流 i16，大端字节转换；new、payload、to_payload、显示和单位换算；往返测试通过。
- 处理函数返回 Vec<Measurement>，串口层可使用全部结果或 last() 安全取最后一条。
- 串口实测：分多次 read 收齐一帧、连续帧，以及 2500 mV / -100 mA 的收发均成功。只追加本次收到的 [..count]。
- ReceiveStats 累计收到字节数和成功解析的测量条数，每 5 秒报告；已实测 6 帧、42 字节。
- TimedOut 继续接收，其他读取错误退出循环；串口参数可传入接收线程。
- main.rs 中的 parges_args 现在接收 `&[String]`，返回 Config；非法波特率通过 `format!` 保留转换错误原因。
- 串口打开失败时会打印端口名和原因后退出接收函数，已用被占用的 COM11 验证。
- CSV 按每条测量结果写入电压（mV）和电流（mA）。已用两帧对照 `.last()` 和借用遍历的效果。
- 已复写 `open_recoder`：追加打开、查询文件大小、空文件写表头，再返回文件。练习了 `?` 连续传播 I/O 错误，以及在调用方用 `match` 取出 `File`。

## 当前入口

```powershell
cargo run -- COM14 9600
```

main 解析参数后调用 serial_thread_run；当前串口流程会先发送一帧测量数据，再循环接收，Ctrl+C 退出。线程包装启动后立即 join，主线程等待接收线程结束。
